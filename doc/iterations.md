## 2. 实现与首轮验证

- 完成封装图形树及六种多态图形；编辑 Command 持有操作前后快照，History 管理执行顺序，Editor 提供事务边界。文档类操作成功才清空历史并设 IO 屏障。
- `create ... in ...` 在分词时保留“是否被双引号包裹”，避免把文本参数 `"in"` 当归属子句。
- XML 适配器先保留全文所有显式 id，再给匿名元素分配 id；否则前面的匿名 rect 会抢占后面已有的 rect1。
- 首次编译发现 XML 库的 `Element.localName` 类型可能为空；查阅已安装库的声明，使用 `tagName` 作为回退，未用非空断言掩盖类型问题。
- Windows Node 20 不展开测试脚本中的 `*.test.js`。先发现目录模式会把辅助文件也计为测试，随后改为显式列出三个测试入口，避免虚增通过数量。
- 实际子进程测试验证 stdin、`--script`、中文、带空格文件路径、失败后继续、文件保存与读回。
- 首轮测试中一个“自动补 id”用例的警告数量预期误写为 5；对照输入的两个显式 id、四个匿名元素和逐条输出，改为 4，未修改正确的分配逻辑。
- 代码检查发现 CLI 为解析数字直接依赖 domain；增加应用层 `CommandArguments` 入口，使 CLI 仅依赖 application，保持已画出的依赖方向。
